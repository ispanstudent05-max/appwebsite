CORE FEATURES

從記下來，到真的做到。

六個核心功能，把任務、提醒與移動接在一起。

不只看時間，也看你現在在哪、怎麼移動。

  • 依位置與時間判斷提醒
  • 預估車程安排出發提醒
  • 路況明顯變化追加通知
mockup-1

用平常說話的方式，就能把事情記下來。

  • 支援自然語言輸入
  • 自動辨識時間與地點
  • 辨識後可再次確認修改
mockup-2

要去哪裡，直接從任務接著走。

  • 任務直接帶入目的地
  • 提供不同交通方式
  • 從任務直接開始導航
mockup-3

路上真的有變化，才再次提醒你。

  • 持續更新預估車程
  • 車程增加15分鐘才提醒
  • 重要變化才追加通知
mockup-4

到了對的地方，再想起該做的事。

  • 依抵達位置觸發提醒
  • 支援目的地任務提醒
  • 減少過早提醒後遺忘
mockup-5

以為結束了，也不讓小事被落下。

  • 檢查尚未完成的任務
  • 適當時機重新帶回任務
  • 銜接下一個任務行動
